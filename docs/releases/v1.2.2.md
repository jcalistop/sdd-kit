# SDD Kit — versión 1.2.2

> **Estado:** patch de optimización de tokens en reglas, skills y pipeline de generación.

**Fecha de release:** 2026-07-14  
**Repositorio:** https://github.com/jcalistop/sdd-kit

---

## Novedades principales

| Área                         | Qué ganaste                                                                 |
| ---------------------------- | --------------------------------------------------------------------------- |
| **Reglas Cursor**            | Menos reglas `alwaysApply`; `sdd-core` fusionada en `sdd-agent-workflow`    |
| **Skills**                   | Lectura previa solo en draft/build; verify sin cadena circular              |
| **Templates**                | Guía anti-boilerplate en plantilla de spec                                  |
| **install-agents.py**        | Evita duplicar skills globales si ya existen en el proyecto                 |

---

## Actualizar tu proyecto consumidor

1. Bump submodule a tag `v1.2.2`.
2. Reinstala adaptadores: `python sdd-kit/bootstrap/install-agents.py install` (o flujo `upgrade-kit`).
3. Verifica que `.cursor/rules/` tiene una regla always-on menos tras fusionar `sdd-core`.
4. Actualiza `kit.installed_version` a `v1.2.2` en tu `sdd.config.yaml` si el instalador no lo hizo.
