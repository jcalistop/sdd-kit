## Actualizar tu proyecto consumidor

1. Bump submodule a tag `v1.6.0`.
2. Lee **`sdd-kit/core/guides/upgrade-guide.md`** (§ Tras v1.6.0 y checklists v1.3.0…v1.5.0 si vienes de ≤v1.2).
3. Si tienes guías sueltas en la raíz de `paths.sdd`, muévelas a `guides/` con OK humano.
4. Reinstala adaptadores: `python sdd-kit/bootstrap/install-agents.py install …` (o skill `upgrade-kit`).
5. Actualiza `kit.installed_version` a `v1.6.0` y una fila en `UPGRADE-LOG.md`.

Detalle: [`core/guides/upgrade-guide.md`](../../core/guides/upgrade-guide.md) § v1.6.0.
