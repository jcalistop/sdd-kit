## Novedades principales

| Área | Qué cambió |
| ---- | ---------- |
| **install-agents** | `agent.branching_mode` (`feature-pr-dev` \| `solo-push-dev`); skills con `{{BRANCHING_RULES}}`; borra skills `sdd-*` managed en `~/.cursor/skills` (precedencia instancia > global) |
| **Laravel (Voyager + Filament)** | Gate de formato verify/checklist = `vendor/bin/pint --test` (paridad CI); `--dirty` solo tip de autofix |
| **Dogfood** | Informe consumidor externo Centinela cerrado; gaps #1–2 cerrados en esta versión |

---

## Actualizar tu proyecto consumidor

1. Bump submodule a tag `v1.5.0`.
2. Declara en `sdd.config.yaml` (opcional; default `feature-pr-dev`):

   ```yaml
   agent:
     branching_mode: feature-pr-dev  # o solo-push-dev
   ```

3. Reinstala adaptadores: `python sdd-kit/bootstrap/install-agents.py install …` (o upgrade-kit).  
   Esto reescribe skills del proyecto y elimina `sdd-*` del manifest en `~/.cursor/skills` si existían.
4. Perfiles Laravel: verify usa `vendor/bin/pint --test` (no `--dirty` como evidencia).
5. Actualiza `kit.installed_version` a `v1.5.0` y una fila en `UPGRADE-LOG.md`.

Detalle: [`core/upgrade-guide.md`](../../core/upgrade-guide.md) § v1.5.0.
