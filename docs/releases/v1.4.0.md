| **Consumidor** | Sin cambio de API ni de skills/prompts                                     |

---

## Actualizar tu proyecto consumidor

1. Bump submodule a tag `v1.4.0` (o commit de release).
2. Ejecuta `python sdd-kit/cli/sdd.py validate` (opcional pero recomendado).
3. Actualiza `kit.installed_version` a `v1.4.0` y una fila en `UPGRADE-LOG.md`.
4. Reinstalar agentes **no es obligatorio** solo por esta versión.

Detalle: [`core/upgrade-guide.md`](../../core/upgrade-guide.md) § v1.4.0.
