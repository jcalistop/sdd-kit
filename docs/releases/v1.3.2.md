## Novedades principales

| Área                  | Qué cambió                                                                 |

| **CLI**               | Eliminado `sdd metrics tokens`. `sdd metrics` sigue midiendo salud SDD     |

| **Skills**            | Eliminada `sdd-cost-governance` (ya no se instala)                         |
| **Conservado**        | Two-zone, plantilla compacta, grafo de dependencias, umbral «¿necesita spec?» |

---

## Actualizar tu proyecto consumidor

1. Bump submodule a tag `v1.3.2` (o commit de release).
2. Reinstala adaptadores (`install-agents.py` / skill `upgrade-kit`) — obligatorio si tenías skills de v1.3.x.
3. Si quedó `.cursor/skills/sdd-cost-governance/`, bórrala.
4. Deja de llamar `sdd metrics tokens` (el subcomando ya no existe).
5. Ejecuta `python sdd-kit/cli/sdd.py validate`.
6. Actualiza `kit.installed_version` a `v1.3.2` y una fila en `UPGRADE-LOG.md`.

Detalle: [`core/upgrade-guide.md`](../../core/upgrade-guide.md) § v1.3.2.
