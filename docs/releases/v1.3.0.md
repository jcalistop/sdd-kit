## Actualizar tu proyecto consumidor

**Camino recomendado:** flujo agentico **`upgrade-kit`** (skill `sdd-upgrade-kit`).

1. Lee el runbook [`core/upgrade-guide.md`](../../core/upgrade-guide.md) (fuente de verdad).
2. Pide al agente: *«Actualiza el kit SDD a v1.3.0»* o ejecuta:
   ```bash
   python sdd-kit/cli/sdd.py prompt show upgrade-kit --full
   ```
3. El flujo hace: detectar versión → changelog → bump submodule → merge instancia (con tu OK) → reinstalar **prompts y skills** → `validate-sdd` → `kit.installed_version` + `UPGRADE-LOG.md`.

**No basta** con solo `git submodule update` / checkout del tag: sin reinstalar adaptadores no llegan `sdd-safe-git` ni `sdd-cost-governance`.

### Checklist post-upgrade (v1.3.0)

- [ ] `.cursor/rules/sdd-safe-git.mdc` existe con `alwaysApply: true`
- [ ] Skill `sdd-cost-governance` instalada (manifest / `.cursor/skills/`)
- [ ] `validate-sdd` muestra prefijos `[componente]` (p. ej. `[backlog]`, `[specs]`)
- [ ] Opcional: `python sdd-kit/cli/sdd.py metrics tokens --summary`
- [ ] `kit.installed_version: "v1.3.0"` y fila en `UPGRADE-LOG.md`

Detalle: sección **Tras v1.3.0+** en [`upgrade-guide.md`](../../core/upgrade-guide.md).
